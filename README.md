# justinsmithphd.com

Static Jekyll site, served by GitHub Pages.

- `index.html` - home screen (planet approach, neural camo background, typewriter intro).
- `assets/typewriter.js` - intro text and links.
- `assets/camo.js` - WebGL background. Flight tuning (APPROACH, H_FAR, H_LAND) and scroll sensitivity are near the bottom.
- `_config.yml` - site title and description.
